Перемикайте розкладки клавіатури на Mac, як у Windows.

LangCycle — безкоштовна програма для рядка меню macOS. Кожне натискання однієї гарячої клавіші вмикає наступну мову введення за фіксованим порядком: A → B → C → A. Великий індикатор показує обрану мову.

Навіщо одна клавіша для всіх мов введення?

Якщо ви друкуєте двома чи більше мовами на Mac, вбудоване скорочення може заважати. LangCycle робить перемикання джерел введення передбачуваним.

Скорочення macOS

Стандартне скорочення джерела введення повертає до розкладки, яку ви використовували перед цим. З двома мовами це працює. З трьома і більше пройти їх по колу однією клавішею неможливо, а щоб побачити, де ви опинилися, доводиться дивитися на рядок меню.

LangCycle

Одна й та сама клавіша завжди веде вперед по вашому списку розкладок, як Alt+Shift чи Win+Space у Windows. Додайте ⇧, щоб піти назад. Індикатор називає обрану мову, тож ви не надрукуєте рядок не тією.

Підійде тим, хто пише українською, англійською, німецькою, польською чи будь-яким поєднанням мов і розкладок, а також усім, хто переходить із Windows на Mac.

Одне налаштування під час першого запуску

macOS використовує ⌃Space для власного перемикача джерел введення і обробляє цю клавішу першою. Вимкніть це один раз — і LangCycle візьме керування на себе.

  1. Відкрийте налаштування скороченьСистемні параметри → Клавіатура → Комбінації клавіш… → Джерела введення.
  2. Зніміть позначки з двох скорочень джерел введення«Вибрати попереднє джерело введення» і «Вибрати наступне джерело в меню введення».
  3. Обрали ⌘Space? Є ще один крокТакож зніміть позначку Spotlight → «Показати пошук Spotlight».

LangCycle показує ці кроки під час першого запуску, а пізніше — у пункті меню Setup Help…. Якщо скорочення все ще конфліктує, меню покаже ⚠︎ Shortcut unavailable. Назви пунктів у macOS можуть відрізнятися залежно від мови системи.

Встановлення

Apple не нотаріально засвідчила LangCycle (для цього потрібен платний обліковий запис Apple Developer), програма лише підписана ad-hoc. Тому macOS сприймає завантажену копію як програму від невідомого розробника. Обидва способи нижче це враховують.

Homebrew

brew install --cask mavr1k/tap/langcycle

Cask знімає з програми позначку карантину, тож macOS не показує попередження. Оновлюйте командою brew upgrade --cask langcycle.

Завантаження

  1. Завантажте останній zip і розпакуйте його.
  2. Перетягніть LangCycle.app у /Applications.
  3. Відкрийте програму. Коли macOS відмовить, натисніть Готово, потім відкрийте Системні параметри → Приватність і безпека та натисніть Усе одно відкрити. Це потрібно зробити лише раз.

Хочете зібрати самі? Клонуйте репозиторій і виконайте ./build.sh. Потрібні лише Command Line Tools від Apple, Xcode не потрібен. Інструкція зі збирання (англійською).

Приватність за задумом

Тут майже нічого не потрібно брати на віру, і все можна перевірити: код відкритий і короткий.

Лише гаряча клавіша

Програма використовує RegisterEventHotKey з Carbon, якому не потрібен особливий доступ. Те, що ви друкуєте, не читається і не записується.

Оновлення лише за вашою згодою

Приблизно раз на день програма перевіряє GitHub на наявність нового релізу і нічого не завантажує, доки ви не оберете встановлення. Перед встановленням перевіряються SHA-256 від GitHub і підпис програми. Зніміть позначку Check for Updates Automatically — і програма взагалі не виходитиме в мережу.

На цьому сайті немає ні аналітики, ні сторонніх скриптів чи шрифтів. Єдиний запит — до публічного API GitHub, щоб показати поточну версію на кнопці завантаження.

Питання про перемикання розкладок на Mac

Як перемикати мову клавіатури на Mac однією комбінацією?

Встановіть LangCycle, один раз вимкніть системні скорочення джерел введення і натискайте ⌃Space. Кожне натискання вмикає наступну розкладку зі списку. ⌃⇧Space повертає до попередньої.

Чи є для Mac перемикач розкладок, як у Windows?

Так, саме це робить LangCycle: одна гаряча клавіша перебирає ваші розкладки по колу у фіксованому порядку, а не стрибає між двома останніми.

Чи безкоштовний LangCycle?

Так. Це програма з відкритим кодом під ліцензією MIT, без реклами, облікових записів і аналітики.

Чому macOS каже, що не може перевірити LangCycle?

Програма не нотаріально засвідчена, бо для цього потрібен платний обліковий запис Apple Developer. Встановіть через Homebrew або один раз скористайтеся кнопкою Усе одно відкрити у Системні параметри → Приватність і безпека. Вихідний код відкритий, а релізи збирає GitHub Actions.

Чи працює це з ⌘Space або ⌥Space?

Так. Оберіть гарячу клавішу в меню. Для ⌘Space також вимкніть скорочення Spotlight. Додавання ⇧ завжди перемикає назад.

Які Mac підтримуються?

macOS 13 або новіша, на Apple Silicon та Intel. Програма універсальна.

Чи працює це в полі для пароля?

Гарячі клавіші Carbon зазвичай працюють і за ввімкненого безпечного введення, але для поточної збірки це ще не перевірено.

Як видалити програму?

Вимкніть Launch at Login і вийдіть із LangCycle, потім видаліть програму. З Homebrew виконайте brew uninstall --cask --zap langcycle — це також видалить збережені налаштування. Якщо хочете повернути системне скорочення, увімкніть його знову в налаштуваннях клавіатури.
