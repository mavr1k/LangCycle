Switch keyboard layouts on Mac the way Windows does.

LangCycle is a free menu bar app for macOS. Every press of one hotkey moves to the next input language in a fixed order: A → B → C → A. A large indicator shows the language you picked.

Why one key for every input language?

If you type in two or more languages on a Mac, the built-in shortcut can feel wrong. LangCycle makes switching input sources predictable.

The macOS shortcut

The default input source shortcut jumps back to the layout you used before. With two languages that works. With three or more, you can't walk through them with one key, and you have to look at the menu bar to see where you landed.

LangCycle

The same key always moves forward through your layouts, the way Alt+Shift or Win+Space does on Windows. Add ⇧ to go back. The HUD names the language you picked, so you never type a line in the wrong one.

Good for people who write in English, Ukrainian, German, Polish, Spanish or any mix of languages and keyboard layouts, and for anyone moving from Windows to Mac.

One thing to do on first run

macOS uses ⌃Space for its own input switcher and handles the key first. Turn that off once and LangCycle takes over.

  1. Open the shortcut settingsSystem Settings → Keyboard → Keyboard Shortcuts… → Input Sources.
  2. Untick the two input source shortcuts“Select the previous input source” and “Select next source in Input menu”.
  3. Using ⌘Space? One moreAlso untick Spotlight → “Show Spotlight search”.

LangCycle shows these steps on first launch and later under Setup Help… in its menu. If a shortcut still conflicts, the menu says ⚠︎ Shortcut unavailable.

Install

LangCycle is not notarized by Apple (that needs a paid Apple Developer account); it is only ad-hoc signed. So macOS treats a downloaded copy as coming from an unidentified developer. Both ways below deal with that.

Homebrew

brew install --cask mavr1k/tap/langcycle

The cask removes the download quarantine flag, so macOS shows no warning. Update later with brew upgrade --cask langcycle.

Download

  1. Get the latest zip and unzip it.
  2. Drag LangCycle.app into /Applications.
  3. Open it. When macOS refuses, click Done, then go to System Settings → Privacy & Security and click Open Anyway. You only do this once.

Prefer to build it yourself? Clone the repository and run ./build.sh. Only Apple's Command Line Tools are needed, not Xcode. Build instructions.

Private by design

There's very little to trust, and you can check all of it: the code is open and short.

Only the hotkey reaches it

It uses Carbon's RegisterEventHotKey, which needs no special access. Nothing you type is read or logged.

Updates only when you say so

It checks GitHub for a new release about once a day and downloads nothing until you choose to install. Installs are checked against GitHub's SHA-256 fingerprint and the app's signature. Untick Check for Updates Automatically and the app makes no network connections at all.

This website has no analytics and no third-party scripts or fonts. Its only request is to GitHub's public API, to show the current version on the download button.

Questions about switching layouts on Mac

How do I switch keyboard language on a Mac with one shortcut?

Install LangCycle, turn off the macOS input source shortcuts once, then press ⌃Space. Each press selects the next enabled layout. ⌃⇧Space goes to the previous one.

Is there a Windows-style language switcher for Mac?

Yes, that is what LangCycle does: one hotkey cycles through your keyboard layouts in a fixed order, instead of jumping between the last two.

Is LangCycle free?

Yes. It is open source under the MIT license, with no ads, no accounts and no analytics.

Why does macOS say it can't verify LangCycle?

The app is not notarized, because notarization needs a paid Apple Developer account. Install with Homebrew, or use Open Anyway in System Settings → Privacy & Security once. The source is public and releases are built by GitHub Actions.

Does it work with ⌘Space or ⌥Space?

Yes. Choose the hotkey in the menu. With ⌘Space, also turn off Spotlight's shortcut. Adding ⇧ always goes backwards.

Which Macs are supported?

macOS 13 or later, on Apple Silicon and Intel. The app is a universal build.

Does it work while a password field is focused?

Carbon hotkeys usually keep working while secure input is on, but this has not been verified for the current build yet.

How do I uninstall it?

Turn off Launch at Login and quit LangCycle, then delete the app. With Homebrew run brew uninstall --cask --zap langcycle, which also removes the saved settings. Re-enable macOS's own shortcut in Keyboard Shortcuts if you want it back.
